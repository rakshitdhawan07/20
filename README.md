# CS F301 Assignment 2 — Group 20

Logic and functional programming: two Prolog problems, two Scheme problems.
Layout per the assignment brief: `20/code`, `20/tests`, `20/skills`, `20/prompts`.

## Development environment

Target per the brief: SWI-Prolog 9.x, Racket 8.x.
Developed and tested on WSL Ubuntu 20.04 with the distribution packages,
SWI-Prolog 7.6.4 and Racket 7.2. Code is written to the intersection of
these and the target versions: no predicate or form newer than 7.6/7.2 is
used, so it runs unchanged on 9.x/8.x.
