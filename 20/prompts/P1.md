# prompts/P1.md — P1: Department Assignment Puzzle, Reloaded

Every prompt given to the AI assistant for P1, word for word, in the order
they were given. Per the assignment's decomposition rule, no prompt asks for
the complete solution to the problem: each one is a single unit of work — one
predicate, or one group of clauses of one predicate — and each produced one
commit.

The assistant was working under `skills/prolog-dev/SKILL.md`, which is why
every prompt names it rather than restating the conventions.

## Notes on the decomposition

The order was chosen so that each unit could be checked before the next was
written. The clues came first because they are pure tests and can be exercised
against a hand-written assignment without any solver existing; the generator
second, because once it existed the clue counts could be compared against an
independently computed table; `main/0`, `count_solutions/2` and the repair
last, each of which only composes what was already verified.

Two prompts were deliberately *not* asked, because they would have requested
a whole problem in one unit: "solve the puzzle" and "write 20_q1.pl".

Process prompts that were not units of work on P1 — asking which problem to
start next, and asking for this file — are recorded in `prompts/SETUP.md`
rather than here.
